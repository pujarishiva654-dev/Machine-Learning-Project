# 🌦️ Weather Prediction ML Project

## 📌 Description
This project focuses on building a Weather Prediction System using Machine Learning techniques in Python. The objective is to analyze historical weather data and predict future weather conditions based on different environmental features.

The project includes data preprocessing steps such as handling missing values, removing duplicates, encoding categorical variables, and scaling numerical data. Exploratory Data Analysis (EDA) is performed using visualizations like heatmaps and boxplots to understand data patterns.

Multiple machine learning models such as Logistic Regression, Decision Tree, and Random Forest are implemented and compared. The dataset is split into training and testing sets to evaluate model performance. Random Forest generally provides better accuracy due to its ensemble learning approach.

This project demonstrates the complete ML pipeline and helps in understanding real-world machine learning workflows.

## 📊 Features
- Data Cleaning and Preprocessing  
- Missing Value Handling  
- Data Visualization (Heatmap, Boxplot)  
- Feature Encoding and Scaling  
- Machine Learning Model Training  
- Model Comparison
